# Email signature assets

Images for email signatures, hosted with GitHub Pages so mail apps can load them.

Each brand has its own folder. The folder's web address is what goes into the signature builder's **Icon folder URL** field.

| Brand | Folder | Icon folder URL |
| --- | --- | --- |
| ZenoXperience | `zenoxperience/` | `https://alexpardonxd.github.io/zeno-signature/zenoxperience/` |

## Adding a brand

1. Create a new folder named after the brand in lowercase, e.g. `acme/`.
2. Add that brand's logo and icon PNGs to it.
3. Add a row to the table above.

Keep file names stable once a signature is in use. Renaming or deleting a file breaks every email already sent with it.
